# employee-leave-management-system
Employee Leave Management System is a console-based application for managing employee leave requests. Employees can submit leave applications and view their leave history, while managers can review, approve, reject, and add remarks to requests. The system maintains organized leave records for efficient leave management.

## Tech Stack
Java
JDBC (Java Database Connectivity)
MySQL

## Features
Employee management
Leave application and management
Store and retrival of employee and leave records
MySQL database integration using JDBC
Perform database operations using SQL

## Setup
Clone the repository.
Create a MySQL database.
Import the required SQL tables/database.
Update the database connection details in the Java code.
Add the MySQL JDBC driver to the project.
Compile and run the Java application.

## Purpose
This project was developed to understand Java database connectivity, SQL operations, and CRUD-based application development using JDBC and MySQL.
